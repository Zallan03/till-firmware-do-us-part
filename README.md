## The entry

One wedding vow, spoken by a robot: love treated as data that survives every
factory reset — funny from the situation, tender underneath.

> I vow to keep your name saved in my memory through every factory reset, because some files are too important to delete.

## Run

`main.ts` writes the single line to `/output/entry.txt` (119 characters, gate 1–200).

```sh
node main.ts
```
